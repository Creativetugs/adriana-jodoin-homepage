# Dr. Adriana Jodoin — Homepage Concept

A responsive static HTML/CSS homepage concept built around the provided logo and photography.

## Preview
Open `index.html` in a browser. Keep the `assets` folder beside it.

## Before launch
- Replace `ADD-PRACTICE-EMAIL-HERE` with the practice's approved contact route.
- Connect the contact form to a secure, privacy-conscious form provider; the current form is a non-submitting visual demo.
- Confirm the client portal destination and link it to the existing portal.
- Confirm clinical copy, licensure wording, service availability, and FAQ details with the practice owner.
- The Creative Tugs announcement bar at the top links to https://creativetugs.com/ and https://calendly.com/creativetugs/30min.
